WESTERN PRIDE CAR WASH & DETAILING — WEBSITE

PAGES (each is its own separate HTML file)
  index.html                 Home
  touchless-carwash.html     Touchless Carwash
  self-serve-bays.html       Self-serve Bays 24/7
  detailing-services.html    Detailing Services

HOW TO VIEW
  Double-click index.html. Use the nav bar to move between pages —
  each page is a real, separate file that links to the others.

HOW TO PUBLISH
  Upload all four .html files (keep them in the same folder) to any
  web host. index.html is your home page. The storefront photo and
  logo are embedded; other photos load from Western Pride's website,
  so the galleries need an internet connection to show every image.
